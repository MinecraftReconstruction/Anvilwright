# Behaviour difference disclosure (Fabric Tinkers' Construct vs Forge upstream)

> For what this project is, see [ATTRIBUTION.md](../ATTRIBUTION.md). This file records **every known place where this port behaves differently from Forge upstream**.
> Any change that is not a semantically equivalent replacement gets a row here. Mantle's copy of this file is at
> [Mantle-Fabric/docs/BEHAVIOUR-DIFFERENCES.md](https://github.com/MinecraftReconstruction/Mantle-Fabric/blob/mcr/mantle-1.11/docs/BEHAVIOUR-DIFFERENCES.md).
